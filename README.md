🦺 Detector de EPP con YOLO

Sistema de detección de Equipo de Protección Personal en obras de construcción. Sube una foto de un trabajador y el modelo identifica si tiene puesto el casco, chaleco de seguridad, guantes, gafas y arnés de alturas.

🚨 Si detecta que falta algún elemento de seguridad, muestra una alerta indicando exactamente qué hace falta y cuántos casos encontró.

🚀 Ver la app en vivo: https://detector-cxwgkhijxmejdsqysecjpz.streamlit.app (Si ves un emoji de Zzzz, presiona el botón azul para despertarla)"

🛠️ Tecnologías: Python, Streamlit, YOLOv8 (Ultralytics), modelo pre-entrenado de detección de EPP (Hugging Face)
